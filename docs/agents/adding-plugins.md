# Adding a plugin or skill

## New plugin

Touch these files, all in one commit:

1. `plugins/<name>/.claude-plugin/plugin.json`, copied from `plugins/healthy-food/.claude-plugin/plugin.json`: set `name`, `description`, `keywords`, and the `repository` path. Start at `"version": "0.0.1"`. Keep `author` and `license` (`GPL-3.0-only`) as they are.
2. `plugins/<name>/skills/<skill>/SKILL.md` — see [New skill](#new-skill).
3. `.claude-plugin/marketplace.json`: append an entry to `plugins[]` (the array is in insertion order, not sorted) with the same `name` and `description` as `plugin.json`, the same `author` (name and email only), `source: ./plugins/<name>`, and a `category` reused from existing entries (`development`, `writing`, `education`, `health`) where one fits.
4. `README.md`: add one install line to each of the two install blocks (`/plugin install …` and `claude plugin install …`).

## New skill

`plugins/<plugin>/skills/<skill>/SKILL.md`, with frontmatter `name` and `description`. Add `disable-model-invocation: true` when the skill should run only when the user types its slash command.

## Generated by the pre-commit hook

`scripts/bump-plugin-versions.mjs` runs on every commit. It patch-bumps the `version` of each plugin the commit touches, regenerates the README table between the `PLUGIN-VERSIONS` markers, and patch-bumps `metadata.version` in `marketplace.json` whenever `plugins[]` changes. Leave all three alone; a hand bump is a double bump.

## Checking

`npm run check` runs formatting, typecheck, and `scripts/validate.mjs`, which enforces the naming, sync, and README ordering rules above plus `claude plugin validate --strict`. Pre-push and CI run the same command.
