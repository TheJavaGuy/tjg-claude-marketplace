# Prose Tightening

Three passes, strictly in order, each working on the previous pass's output. A pass touches only what it owns — the sequence exists so every edit is attributable to exactly one pass.

Before starting: if it isn't stated whether the text is a video script, ask — the answer decides whether pass 3 runs.

## Pass 1 — Copyedit

Fix grammar and punctuation. Fix a spelling only when you are sure it is a misspelling; when in doubt, leave the word. Word choice, rhythm, and structure pass through untouched.

Done when the text is grammatically clean and every edit is a grammar, punctuation, or certain-misspelling fix.

## Pass 2 — Naturalize

Make the text sound slightly more like a native US speaker. Where nearby words or phrases obviously repeat, vary them — a synonym, or a small change of sentence structure. A tad: the author's voice stays, and a sentence that already works stays as written.

Done when every edit is justifiable as either non-native phrasing or nearby repetition, and the rest of the text is verbatim from pass 1.

## Pass 3 — Delivery cues (video scripts only)

Prefix each paragraph with a bracketed speaker direction — **[excited]**, **[serious]**, **[fast]**, **[slower]**, or any cue that keeps the listener striving for more. Vary the register: a script delivered on one note loses the listener.

Done when every paragraph carries exactly one cue and the cues change register across the script.

## Output

Run all applicable passes internally, then deliver in one message:

1. The final text
2. One line per pass summarizing what it changed (or "no changes needed")

Done when the final text and the per-pass summary are both in the reply.
